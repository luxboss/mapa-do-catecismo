# O Mapa Mental do Catecismo — página de vendas

Página estática (HTML + CSS) com contador regressivo diário e FAQ em acordeão.

## Como abrir
Abra `index.html` no navegador, ou sirva a pasta:

    python -m http.server 8000

## Links de checkout
No final do `index.html`, edite o bloco:

    var LINKS={BASICA:"#oferta",SUPER:"#oferta"};

## Estrutura
- `index.html` — página
- `assets/` — CSS e imagens
- `videos/` — vídeo da página
- `identidade-visual.md` — guia de cores, fontes e prompts de imagem
